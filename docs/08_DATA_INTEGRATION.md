# 🔌 ربط بيانات المصنع

## ١. ثلاثة أنواع من الحقيقة

| النوع | المثال | ما يظهر للمستخدم |
|---|---|---|
| مقاس فعليًا | مسح باركود عند استلام شحنة | مصدر وتوقيت آخر قراءة |
| مستنتج | موضع تقريبي بين مسحتي وصول | علامة تقدير ومدى الثقة إن توفر |
| محاكى | تجربة إضافة تروللي | اسم السيناريو وافتراضاته |

لا يمكن معرفة كل حركة فعلية من ملفات إنتاج يومية وحدها. غياب قراءة موقع لا يبرر عرض مسار متوقع على أنه حركة مؤكدة.

## ٢. مراحل الربط

١. استيراد تخطيط وكتالوج وأزمنة ومخزون ابتدائي من ملفات معتمدة.

٢. إعادة تشغيل أحداث تاريخية ومقارنتها بنتائج معلومة.

٣. استقبال تحديثات دورية للطلبات والمخزون وحالات المعدات.

٤. تحديثات أقرب للحظية عند توافر مصادر وحساسات وواجهات مناسبة.

٥. أي أوامر تشغيل فعلية للمعدات مشروع منفصل بنطاق وصلاحيات واضحين؛ ليس ضمن هذه الخطة الأولى.

## ٣. عقد المشاهدة

```text
observation_id, source_system, source_event_id, entity_mapping,
observed_at, received_at, value, unit, quality, provenance
```

توقيت الحدث مختلف عن وقت وصوله. تحفظ المنطقة الزمنية أو توقيت موحد وتحول للعرض محليًا. مصدر كل حقل واضح عند تعدد الأنظمة.

## ٤. إدخال البيانات

قراءة المصدر، ثم منطقة تجهيز، ثم تطبيع الوحدات والأسماء، ثم مطابقة الهويات، ثم فحص جودة، ثم معاينة فروق، ثم اعتماد نسخة أو أحداث.

رسالة مكررة لا تضاعف إنتاجًا أو مخزونًا. رسالة متأخرة لا تعيد الحالة للخلف بصمت. رسالة متعارضة تحفظ مع سبب المعالجة أو التصحيح. معرفات المصنع لا تُستبدل بأسماء عرض متغيرة.

## ٥. مصادر محتملة

| المصدر | استخدامه |
|---|---|
| مخطط الموقع وقياسات المعدات | الأبعاد والممرات والخدمات |
| قوائم الأصناف والوصفات | توافق الأجزاء واستهلاكها |
| أوامر الإنتاج والطلبات | أهداف وتواريخ وأولويات |
| نظام تنفيذ التصنيع | حالة أو أحداث إنتاج وفق المتاح |
| نظام المخازن | مواقع ورصيد وحركات ووحدات مناولة |
| أنظمة الجودة والصيانة | حجز وإصلاح وأعطال وتوقفات |
| باركود أو تحديد مواقع | إثبات وصول أو حركة عند نقاط تغطية |

توافر هذه المصادر وحقولها يحتاج جردًا فعليًا؛ القائمة ليست ادعاء بوجود موصل جاهز لأي نظام.

## ٦. بيئة المصنع المقيدة

التصميم المقترح يدعم التشغيل المحلي دون اعتماد أساسي على الإنترنت. افحص قيود التثبيت والتوزيع والملفات المحمية على الجهاز المستهدف.

إذا كانت ملفات المكتب محمية وتتطلب برنامج المكتب المعتمد، يتم استخراجها عبر واجهاته المسموحة وبصلاحيات المستخدم، وبوضع قراءة فقط عندما يكون المطلوب الاستيراد. لا نفترض إمكانية قراءة الملف بمكتبة ملفات مباشرة، ولا نحاول تجاوز الحماية.

لا تخزن بيانات اعتماد داخل ملف المصنع. توضع بيانات الاتصال في إعدادات محلية مناسبة. العينات عامة واصطناعية، ولا تحتوي أسماء عمال أو أسرار مصنع.

## ٧. التحقق والمعايرة

اختر فترة تاريخية معروفة للمقارنة، ووحدودًا معلنة للإنتاج وزمن المرور والمخزون. عاير على فترة، واختبر على فترة مستقلة. الاختلاف يوثق: بيانات ناقصة، أو افتراض زمني، أو قاعدة تشغيل غير ممثلة.

التطابق في الإجمالي وحده غير كافٍ؛ راجع توزيع الانتظار وحالات نقص الخامة وامتلاء المخارج وحركة المخزون. كل تعديل معايرة يحفظ بإصدار وتجربة جديدة.

## ٨. الانقطاع والتصحيح

المعلومة القديمة تظهر بعمرها. عند انقطاع المصدر لا يتحول التقدير إلى قراءة فعلية. إعادة الاتصال تعالج التكرار والفجوات وترتيب الأحداث. تسوية الجرد تسجل كتصحيح معلوم السبب، لا كاستبدال صامت للرصد السابق.
