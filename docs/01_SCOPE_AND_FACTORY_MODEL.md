# 🧩 نطاق المصنع وتصنيف عناصره

## ١. القطاعات القابلة للتكوين

التقسيم التالي كتالوج أولي؛ عدد القطاعات أو دمجها ليس ثابتًا ولا شرطًا في المحرك.

| القطاع | عناصره الأساسية | المخرجات والحركات |
|---|---|---|
| الاستلام والخامات | بوابات، منطقة تفريغ، فحص وارد، حجر، راكات وصوامع | قبول، حجز، تخزين، صرف، مرتجع مورد |
| حقن البلاستيك | ماكينات، قوالب، مغذيات، تبريد، تشذيب وفحص | فريمات وقطع بلاستيك، هالك ومواد مسترجعة حسب السياسة |
| تشكيل المعادن | تغذية خام، مكابس، قوالب، مناولة وفحص | ظهر معدني وحوامل، قصاصات وهالك |
| البوردات | طباعة معجون، فحص، تركيب مكونات، فرن، فحص بصري ووظيفي | بوردات مجمعة، إصلاح، تحميل برمجيات واختبار |
| موديول الشاشة | تجهيز إضاءة وطبقات بصرية وزجاج وتجميع وفحص | موديولات حسب الموديل؛ متطلبات مناطق نظيفة |
| الفوم | توسعة أولية عند الحاجة، تعتيق، تشكيل، تبريد وتجفيف وفحص | أطقم تغليف، هالك، إعادة استخدام إن كانت معتمدة |
| التجميع النهائي | تغذية محطات، تركيب أجزاء، توصيلات، فحص وتشغيل | أجهزة مكتملة أو موجهة للإصلاح |
| التعبئة | فوم وكرتون وملصقات وملحقات وإغلاق وربط | أجهزة معبأة أو وحدات مناولة |
| المنتج التام والشحن | تخزين، حجز طلب، تجميع شحنة، رصيف، حاوية | تحميل، تأكيد خروج، رفض أو إعادة ترتيب |
| الخدمات المشتركة | صيانة، جودة، أدوات، قوالب، شحن بطاريات ومرافق | موارد مشتركة وقيود تشغيل |

ترتيب العمليات الفعلي يُستخرج من المصنع لكل موديل؛ هذا الكتالوج لا يفرض تسلسلًا موحدًا لكل المصانع.

## ٢. عائلات العناصر

| العائلة | أمثلة | التمثيل المطلوب |
|---|---|---|
| مبانٍ وحدود | أرضيات، أعمدة، أبواب، ميزانين | أبعاد حقيقية وقيود مرور |
| مناطق وخطوط | غرفة نظيفة، خط تجميع | تنظيم ونطاق ومراجع موارد |
| معدات ومحطات | مكبس، فرن، منصة برمجة | قدرات وعمليات ومنافذ |
| تخزين | خانة راك، موقع أرضي، مخزن جانب خط | سعة وتوافق ومواقع متاحة |
| نقل | تروللي، كلارك، ناقل آلي، قطار سحب | حمولة وأبعاد وحركة وطاقة |
| أشخاص وفرق | عامل، مناول، فني صيانة | مهارات ووردية وتكليف وموقع |
| مواد ومنتجات | خامة، بوردة، موديول، جهاز | صنف وكمية وحالة وتتبع |
| وحدات مناولة | صندوق، صينية، بالته، حامل | محتويات ووزن وأبعاد وهوية |
| أدوات وتجهيز | قالب، عدة، منصة اختبار | توافق وحجز وتغيير وصيانة |
| أعمال وطلبات | أمر إنتاج، مهمة نقل، طلب شحن | حالة وأولوية وموارد ومواعيد |

## ٣. العلاقات التي يجب عدم خلطها

| العلاقة | معناها | مثال |
|---|---|---|
| تبعية إدارية | الجهة المسؤولة | كلارك تابع للمخزن |
| تركيب مكاني | جسم ثابت داخل تجميع آخر | محطة مثبتة ضمن خط |
| احتواء | من يحمل أو يحتوي المادة الآن | صينية بوردات داخل تروللي |
| تكليف | العمل المطلوب من مورد | عامل مكلّف بمحطة |
| ارتباط حركة مؤقت | حركة مشتركة بمدة محددة | عامل يدفع تروللي |
| تدفق عملية | أي خطوة تلي أي خطوة وبأي شرط | فحص ثم قبول أو إصلاح |
| اتصال مسار | إمكانية المرور بين نقطتين | ممر مسموح للكلارك |
| اتصال خدمات | متطلبات تشغيل المكان | كهرباء وهواء وشفط وشبكة |

لا تعني التبعية الإدارية أن العنصر يتحرك مع القسم. لا تعني إقامة عامل داخل منطقة أنه تابع لها إداريًا. لا يجوز أن يكون للعنصر أكثر من حاضن مادي في نفس اللحظة.

## ٤. الشجرة التنظيمية

المؤسسة، ثم الموقع، ثم المنطقة، ثم مركز العمل، ثم وحدة العمل؛ تُطابق المستويات المطلوبة مع معيار تنظيم المعدات عند التكامل. هذه بنية تنظيمية وليست وصفًا لوراثة إحداثيات كل عامل وخامة.

تستقل عنها شجرة التحويلات المكانية للتركيبات الثابتة، مع منع الدورات. المتحركات لها مواقع عالمية أو مرجع حركة مناسب، ويتغير الاحتواء عند التحميل والتفريغ بأحداث واضحة.

## ٥. بطاقة كل عنصر

الهوية الثابتة؛ الاسم؛ نوع العنصر؛ القالب وإصداره؛ القسم؛ موضعه أو الحاضن؛ قدراته؛ منافذه؛ حالته؛ آخر تحديث؛ مصدر البيانات؛ علاقاته؛ وسجل التغييرات.

العنصر القابل للتشغيل يضيف أزمنة وموارد وشروطًا. المادة تضيف الصنف ووحدة القياس والدفعة أو السيريال وحالة الجودة. لا نضيف موقعًا مستقلًا لكل كمية غير متتبعة فرديًا.

## ٦. مكونات قابلة للتركيب

| المكون | الوظيفة |
|---|---|
| الموقع والشكل المشغول | التحويل المكاني وحدود المكان والحركة |
| قدرة العملية | العمليات الممكنة والأزمنة والأدوات والموارد |
| التخزين | التوافق والسعة والحجز وسياسة الصرف |
| الحركة والحمولة | السرعة والمسار والوزن ووحدات المناولة |
| العامل | المهارة والوردية والتوفر والتكليف |
| التتبع | صنف ودفعة وسيريال وسلسلة تصنيع |
| الجودة | قبول وحجر ورفض وإصلاح وأدلة اختبار |
| الخدمات | نقاط الاتصال والاستهلاك والقيود |
| العرض | مراجع الرسومات والألوان والحركات |

تركيب المكونات أسلوب لتنظيم التشغيل، وليس إلزامًا بأن تكون قاعدة بيانات الأعمال نسخة من بنية محرك ألعاب.
