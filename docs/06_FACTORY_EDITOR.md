# 🖱️ محرر المصنع

## ١. مساحة العمل

شجرة تنظيم وبحث وفلاتر، ومكتبة عناصر، ولوحة تخطيط أو مشهد ثلاثي، ولوحة خصائص، وشريط زمن، وقائمة مشاكل، وسجل أوامر وتراجع. اختيار عنصر في أي عرض يحدد هويته في العرض الآخر.

يمكن البحث بالاسم أو الهوية أو الصنف أو الموديل أو القسم أو الحالة. طبقات العرض تفصل المعدات والممرات والخدمات والمخزون والعمال والتنبيهات، دون إلغاء حسابها.

## ٢. الأدوات الأساسية

| الأداة | السلوك المطلوب |
|---|---|
| إضافة | سحب قالب مع أبعاد ومنافذ معلومة |
| تحديد | مفرد ومتعدد وبالمستطيل مع إبراز واضح |
| نقل ودوران | حر أو على شبكة قابلة للتغيير |
| محاذاة وتوزيع | مسافات وخطوط مرجعية واضحة |
| نسخ | هويات جديدة وروابط داخلية يعاد ربطها |
| تجميع | علاقة تركيب صريحة دون تغيير الملكية تلقائيًا |
| إلحاق وفصل | خيار الحفاظ على الموقع العالمي |
| ربط | اقتراح منافذ متوافقة مع معاينة التدفق |
| قفل وإخفاء | القفل يمنع التحرير، والإخفاء بصري فقط |
| حذف | عرض التبعيات المتأثرة ومنع المراجع المكسورة |
| تراجع وإعادة | أوامر متسقة قابلة للتكرار |
| قياس | مسافة ومساحة وزاوية وارتفاع |
| حفظ ومقارنة | إصدارات وفروق تخطيط ونتائج تشغيل |

## ٣. أوضاع العمل

- التصميم: تحرير نسخة تخطيط، دون ادعاء أن المصنع الحقيقي تغير.
- المحاكاة: تشغيل السيناريو؛ تغييرات الموارد تطبق بأمر مؤرخ أو بعد إيقاف مناسب.
- متابعة الواقع: قراءة البيانات المقاسة وإظهار تقديرات الحركة المميزة عنها.
- المقارنة: تجربة نسخة بديلة مع المحافظة على الحالة المرجعية.

التنقل بين الأوضاع ظاهر. لا يسمح سحب مجسم في متابعة الواقع بكتابة موضع حقيقي على أجهزة المصنع.

## ٤. نقل خط كامل

١. تحديد المجموعة الثابتة ومنافذها ومساحات الخدمة والتخزين الملحقة بها. تُعرض العناصر المتحركة المرتبطة تشغيليًا دون ضمها تلقائيًا للنقل.

٢. إنشاء معاينة مؤقتة أثناء السحب؛ لا يعتمد كل موضع يمر عليه المؤشر كتعديل دائم.

٣. حساب التحويلات العالمية، وفحص التداخل والحدود والممرات ومساحات الصيانة والتحميل ووصلات الخدمات.

٤. فحص الوصول لكل منفذ متأثر بحسب نوع الوسيلة، وتوضيح المسارات التي أصبحت غير ممكنة.

٥. اعتماد التغيير كأمر واحد بإصدار جديد، أو رفضه بسبب مفهوم. لا يترك الخط في حالة نصف معدلة.

٦. إبطال مخابئ الطرق المتأثرة، وإعادة التخطيط من الوضع الحالي للمتحركات، وتحديث اللقطات بعد اكتمال انتقال الحالة.

٧. إذا كان التشغيل جاريًا: تؤجل المهمة المتأثرة أو توقف في موضع صالح أو ينشأ سيناريو جديد؛ لا تقفز الشحنة أو العامل إلى مكان الأب الجديد.

## ٥. مستويات التحقق

| المستوى | أمثلة |
|---|---|
| بنيوي | معرف مكرر، مرجع مفقود، دورة في الأبوة |
| هندسي | تداخل ماكينة وعمود، خروج عن حدود المبنى |
| حركي | مسار غير متصل، ممر لا يتسع، دوران غير ممكن |
| تشغيلي | عملية بلا مورد، مدخلات غير متوافقة، مخرج بلا سعة |
| خدمات | وصلة لازمة غير متاحة أو قدرة غير كافية |

النتيجة خطأ يمنع الاعتماد أو تحذير قابل للمراجعة، مع سبب ومكان والعناصر المتأثرة. لا نعرض لونًا وحده؛ نضيف نصًا أو رمزًا للحالة.

## ٦. تحرير الخصائص

الخصائص المعرفة في القالب منفصلة عن تجاوزات النسخة. تعديل نسخة لا يغير جميع المعدات. ترقية القالب تعرض أثرها على نسخه قبل التطبيق.

تغيير سرعة سير أو سعة مخزن أو عدد عمال أثناء التشغيل يحترم العمل الجاري. تقليل السعة دون الرصيد الفعلي يعطي حالة زيادة إشغال، ولا يحذف الزيادة. تقليل العمالة لا يسحب عاملًا من عملية غير قابلة للقطع دون سياسة انتقال.

## ٧. تجربة استخدام بسيطة

النصوص قصيرة، والوحدات ظاهرة، والحقول المهمة أولًا، والتفاصيل الفنية في لوحة متقدمة. خطأ نقل خط يقول «الممر لا يتسع للكلارك» بدل رسالة تقنية مبهمة. واجهة عربية تدعم اتجاه الكتابة، مع رموز وأرقام قابلة للقراءة.

## ٨. قبول المحرر

إنشاء خط، ونسخه، وتدويره، ونقل محطة إليه مع الحفاظ على موقعها، وربط منفذ، وحفظ، وإغلاق، وإعادة فتح، ثم تراجع صحيح. كل ذلك يظهر في العرضين بنفس الهوية والمكان، ويمنع مرجعًا مكسورًا أو مسارًا غير صالح من المرور كتصميم سليم.
