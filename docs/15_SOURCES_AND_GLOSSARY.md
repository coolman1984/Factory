# 📚 المصادر والمصطلحات

راجعت المصادر التالية لتثبيت بعض الفروق المعمارية في مناقشة الخطة. هي مراجع مفاهيم، وليست قائمة مشتريات أو اختيارًا نهائيًا لتقنية، ولا تثبت أن هذا المشروع منفذ أو حاصل على اعتماد معياري.

## ١. مراجع رسمية

| المصدر | ما يدعمه في الخطة |
|---|---|
| [نموذج المعدات حسب الدور](https://reference.opcfoundation.org/specs/OPC-10030/8.2) | التفرقة بين الدور المنطقي والمعدة المادية |
| [عرض معيار تنظيم المعلومات الصناعية](https://opcfoundation.org/markets-collaboration/isa-95/) | تبادل معلومات المعدات والأفراد والمواد بين الأنظمة |
| [معالجة الأحداث في محرك المحاكاة](https://anylogic.help/anylogic/statecharts/event-processing.html) | طابور الأحداث وخطوات الزمن وتغيير الحالة |
| [إنشاء نموذج وضبط زمنه](https://anylogic.help/online/anylogic/ui/create-model.html) | اختلاف الزمن الافتراضي عن العرض المرتبط بالوقت الفعلي |
| [مكتبة مناولة المواد](https://anylogic.help/library-reference-guides/material-handling-library/index.html) | تصنيع ومخازن وتخطيط ونقل كمسؤوليات مترابطة |
| [وسائل النقل وحجزها وحركتها](https://www.anylogic.help/online/libraries/material-handling/transporters.html) | دورة حجز وتحميل ونقل وتحرير المورد |
| [قواعد مرور وسائل النقل](https://anylogic.help/online/libraries/material-handling/transportercontrol.html) | الفرق بين إيجاد الطريق وقواعد استخدامه والتصادم |
| [مكتبة المشاة](https://anylogic.help/online/libraries/pedestrian/index.html) | حركة الأشخاص وتفاعلهم مع العوائق |

باقي القرارات — مثل كاتب الحالة الواحد، وفصل عقود التخزين، وتقسيم مراحل التنفيذ، ومعايير قبول الأصول — مقترحات تصميم لهذه الحالة، وليست اقتباسًا بأن منتجًا محددًا يستخدم المعمارية نفسها.

## ٢. قاموس مختصر

| المصطلح | المعنى هنا |
|---|---|
| المصنع الرقمي | تمثيل منظم للمكان والموارد والعمليات |
| التوأم الرقمي المتصل | نموذج مرتبط ببيانات الواقع مع معرفة تغطيته وتأخيره |
| المحاكاة | حساب سلوك نظام وفق قواعد ومدخلات وافتراضات |
| الكيان | عنصر له هوية ثابتة |
| المكون | مجموعة خصائص أو قدرة تضاف لعنصر |
| القالب | تعريف مشترك لإنشاء نسخ متوافقة |
| النسخة | عنصر محدد في المصنع يستند إلى قالب |
| المنفذ | نقطة عمل أو توصيل ذات هوية ودور |
| الأب المكاني | مرجع تحويل ثابت لمجموعة مركبة |
| العهدة | المكان أو الحاضن الذي توجد فيه المادة فعليًا |
| الحجز | تخصيص مخزون أو مورد قبل الاستخدام |
| وحدة المناولة | صندوق أو صينية أو بالته ذات محتويات |
| وصفة التصنيع | المدخلات والمقادير والمخرجات المتوقعة |
| طريق التشغيل | العمليات وترتيبها وشروط الانتقال |
| حدث | تغيير وقع في زمن محدد |
| أمر | طلب تغيير قد يقبل أو يرفض |
| لقطة حالة | نسخة حالة عند زمن وتسلسل معلومين |
| مستوى التفاصيل | حجم التفاصيل المرئية حسب الغرض والمسافة |
| المعايرة | ضبط افتراضات النموذج على بيانات معروفة |
| التحقق المستقل | اختبار النموذج على بيانات لم تضبط عليها الافتراضات |
