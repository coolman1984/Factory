# 🏭 الخطة الرئيسية

## ١. الهدف

بناء نظام منظم يستطيع تمثيل مصنع تليفزيونات متكامل، وتصميم تخطيطه بحرية، وتشغيل محاكاة لحركة المواد والمعدات والعمال، وعرض الحالة نفسها ثنائيًا وثلاثيًا، ثم ربطها تدريجيًا ببيانات المصنع الفعلية.

يساعد النظام في الإجابة عن أسئلة عملية: أين يتوقف الإنتاج؟ هل النقص بسبب المورد الداخلي أم النقل أم العمالة؟ ما أثر نقل خط أو زيادة تروللي؟ هل يسع المخزن خطة الإنتاج؟ وما أثر التغيير على تكلفة المناولة وزمن التسليم؟

## ٢. أربع قدرات مستقلة ومترابطة

| القدرة | ما تتيحه | دليل النجاح |
|---|---|---|
| تصميم المصنع | إنشاء التخطيط وإضافة ونقل العناصر وربطها | تغيير تخطيط صالح مع حفظ وتراجع |
| محاكاة المصنع | تجربة الإنتاج والأعطال والمخزون والمناولة | نتائج قابلة للتفسير والتكرار |
| مشاهدة المصنع | عرض ثنائي وثلاثي وحركات ومعلومات واضحة | العرضان يعكسان الحالة نفسها |
| ربط الواقع | قراءة أحداث المصنع وبياناته | مصدر وتوقيت وجودة معروفون لكل معلومة |

يمكن إنجاز التصميم والمحاكاة قبل وجود ربط حي. تسمية التجربة «توأمًا متصلًا بالواقع» تتطلب توثيق اتصالها بالبيانات ومدى التغطية والتأخير.

## ٣. نطاق الحياة الكاملة للمنتج

الاستلام وفحص الوارد؛ تخزين الخامات؛ إنتاج البلاستيك والمعادن والفوم والبوردات؛ تحميل البرمجيات والفحص؛ تجميع موديولات الشاشات؛ التجميع النهائي؛ اختبارات المنتج؛ التعبئة؛ تخزين المنتج التام؛ تجهيز الشحنة؛ تحميل الحاوية.

تشمل الدورة أيضًا المرتجعات الداخلية، وحجز الجودة، وإعادة الإصلاح، والهالك، والأدوات والقوالب، وتغيير الموديل، والصيانة، والورديات، والأوقات غير المنتجة، وعودة الحاويات والتروليات الفارغة.

## ٤. ما نحتفظ به من التصور الأول

- فصل عقل المحاكاة عن محرك الرسم.
- تركيب خصائص وسلوكيات على عناصر ذات هوية ثابتة.
- مكتبة قوالب ونسخ منها، وإحداثيات نسبية ونقاط تحميل وتفريغ وربط.
- شبكة تدفق تصنيع وشبكة حركة أرضية منفصلتان.
- محرر بصري بالسحب والتعديل والمعاينة.
- رسم مجمع وتفاصيل تتناسب مع قرب الكاميرا.

## ٥. التصحيحات المعمارية الملزمة للخطة

| التصور المبسط | التصميم المقترح |
|---|---|
| تحديث كل شيء مع كل إطار | أحداث إنتاج مستقلة، وحركة مستمرة عند الحاجة، ورسم مستقل |
| شجرة واحدة تحدد كل التبعيات | علاقات مستقلة للإدارة والتركيب والاحتواء والتكليف |
| كل خامة كيان مرسوم مستقل | تتبع بالوحدة أو الدفعة أو الكمية بحسب الحاجة |
| تدفق تصنيع بلا رجوع | شبكة تشغيل تسمح بإعادة الاختبار والإصلاح والهالك |
| أقرب تروللي يذهب فورًا | حجز خامة ووسيلة وعامل ووجهة مع سياسة أولوية |
| إيجاد الطريق يمنع كل تصادم | تخطيط طريق بالإضافة إلى قواعد مرور وحجز واكتشاف تعطل |
| تعديل موضع الأب يكفي دائمًا | تحقق من التركيب والمسارات والخدمات والمهام الجارية |
| رقم تحميل يكفي للشحن الحقيقي | خطة رص وأوزان وتوافق ومواقع أو وحدات مناولة متتبعة |
| ملف واحد للحقيقة كلها | تعريف بإصدار، وحالة تشغيل، وسجل أحداث، ومصادر خارجية |
| تروللي يدوي يصبح آليًا بتغيير اسم | تبديل قدرات وسياسة حركة وطاقة ومهام مع تحقق من التوافق |

## ٦. حدود أول إصدار

المحاكاة الأولى للتدفق والموارد والمناولة؛ لا تتضمن حسابات فيزيائية تفصيلية لجزيئات الفوم أو صهر البلاستيك أو التشوه المعدني. تمثل هذه العمليات بوصفات وأزمنة وموارد وطاقة وعوائد إنتاج عند توفر البيانات.

حركة العامل مرئية وتؤثر في زمن الانتقال والتوفر والمهارة؛ المحاكاة الدقيقة للأصابع والوضعيات البشرية ليست شرطًا أوليًا لصحة الإنتاج. الحركة السينمائية الإضافية لا تغير نتيجة العملية.

تصادم المجسمات وممرات الإخلاء مؤشرات تخطيطية وفق بيانات أدخلها الفريق؛ اعتماد السلامة الفعلي يحتاج مراجعة مختصة ومواصفات الموقع.

## ٧. مبدأ التنفيذ

ننجز شريحة تشغيل كاملة أولًا، لا مصنعًا واسعًا بمجسمات غير مترابطة. التوسع بالقطاعات والأعداد يحدث بعد إثبات صلاحية نفس عقود البيانات والسلوك والحفظ.

المراحل وشروط الخروج في [خطة التنفيذ](09_ROADMAP.md)، والاختبارات في [خطة التحقق](10_VALIDATION_AND_PERFORMANCE.md).

## ٨. تسليمات التخطيط الحالية

وثائق قرار وتنفيذ، وعينة بيانات افتراضية، ومخطط تحقق بنيوي. العينة ليست وصفًا معتمدًا للمصنع ولا بديلًا عن القياس الميداني. أي أبعاد أو أزمنة أو قدرات فيها للتوضيح فقط.
