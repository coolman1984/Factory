# ✅ خطة التحقق والأداء

## ١. مستويات التحقق

١. صحة الملفات والمراجع والوحدات.

٢. صحة المخزون والموارد والأزمنة والانتقالات.

٣. صحة التحرير والهندسة والطرق.

٤. تطابق العرضين مع الحالة التشغيلية.

٥. أداء وسهولة استخدام على الجهاز المستهدف.

٦. مقارنة التشغيل ببيانات الواقع عند توافرها.

## ٢. حالات قبول أساسية

| المعرف | الحالة | النتيجة المطلوبة |
|---|---|---|
| V01 | معرف مكرر أو أب أو منفذ غير موجود | رفض واضح قبل التشغيل |
| V02 | تدوير مجموعة ثم نقلها | مواقع عالمية صحيحة لكل الأبناء والمنافذ |
| V03 | تغيير الأب مع حفظ الموضع | العنصر لا يقفز |

| V06 | نقص خامة مع شحنة في الطريق | لا طلب زائد لنفس الاحتياج |

| V22 | نسخ خط | هويات جديدة وروابط داخلية صحيحة |
| V23 | فتح إصدار قديم أو ملف تالف | ترحيل على نسخة أو رفض واضح |
| V24 | تكرارات تجربة عشوائية | بذور وإعدادات ونتائج قابلة للإعادة |

## ٣. ثوابت حسابية

- لا رصيد سالب بعد التزام صالح.
- لا مادة في حاضنين، ولا سيريال منتج مرتين، ولا مورد مشغول بعمليتين غير متوافقتين.
- توازن المادة يقاس بوحدات مناسبة مع تسجيل الاستهلاك والمخرجات والهالك والتصحيحات؛ عدد المدخلات لا يلزم أن يساوي عدد المخرجات.
- الأزمنة غير سالبة، وتتابع المهمة صالح، والأحداث لا تنفذ مرتين.
- الحجوزات لا تتجاوز المتاح وقت الالتزام، ولا تظل محجوزة بلا سبب بعد الإلغاء أو التعافي.
- شجرة التحويلات بلا دورات، وكل مرجع مطلوب يشير إلى سجل صالح.

## ٤. سيناريوهات قياس الحجم

| المستوى | محتواه | غرضه |
|---|---|---|
| صغير | دورة كاملة بأعداد قليلة | صحة التشغيل وسهولة التشخيص |
| متوسط | خطوط متعددة وموارد متنافسة | كشف ازدحام الموارد والمرور |
| كبير | أحجام قريبة من بيانات المصنع | إثبات السعة على الجهاز المستهدف |
| ضغط | زيادة تدريجية فوق الحمل المتوقع | تحديد حدود الأداء وطريقة التدهور |

تُثبت الأعداد عند جرد الواقع. العدد المحاسبي للمواد، وعدد وحدات المناولة المتحركة، وعدد المجسمات المرئية أرقام مختلفة يجب قياسها منفصلة.

## ٥. ما نقيسه

- زمن الخطوة الحسابية، وعدد الأحداث المعالجة، وحجم طوابيرها.
- زمن إيجاد طريق وإعادة تخطيط مجموعة متأثرة.
- زمن الاستجابة لأوامر التحرير والتحقق والحفظ والتحميل.
- زمن الإطار وتوزيعه ودرجاته المئينية، وليس المتوسط وحده.
- ذاكرة الحالة والأصول والرسوم، وحجم اللقطات والرسائل.
- سرعة المحاكاة مقارنة بزمن المصنع، مع الرسم وبدونه.
- زمن توقف الواجهة عند إضافة أصل أو فتح مصنع كبير.

تُسجل مواصفات الجهاز ونظامه ودقة الشاشة وإعدادات الجودة وإصدار البرنامج وبيانات السيناريو مع النتائج. لا تُكتب «٦٠ إطارًا» أو «أقل من ٥ مللي ثانية» كضمان قبل هذا القياس.

## ٦. عدالة مقارنة السيناريوهات

السيناريوهات تستخدم نفس الأفق الزمني وشروط البداية والطلب، مع سياسة واضحة لفترة الاستقرار. عند وجود عشوائية تستخدم تكرارات وبذور معلنة؛ يمكن استخدام بذور مشتركة للمقارنة المنضبطة عند ملاءمتها.

نبلغ متوسطًا وتباينًا أو نطاق ثقة مناسبًا، ونوضح الأحداث النادرة والافتراضات الحساسة. لا تختزل النتيجة في أفضل تشغيل فقط.

## ٧. أدلة التسليم

سجل أحداث أو تقرير قابل للإعادة لصحة التشغيل، وصور أو تسجيلات للحركة والتحرير، وتقرير قياس للأداء، ومقارنة مرجعية للدقة عند وجود بيانات فعلية. كل دليل يذكر نسخة التعريف والمحرك والسيناريو.

## ٨. تحقق حزمة التخطيط

قبل نشر هذه الحزمة: فحص روابط الملفات، وصحة قراءة العينة، ومطابقتها للمخطط البنيوي، وعدم تكرار هوياتها، وصحة مراجعها، وتوافق وحداتها، وأن مسار المواد يتضمن مدخلات ومخرجات العمليات المعلنة.

هذا الفحص لا يثبت مرور كلارك فعليًا ولا صحة زمن إنتاج؛ العينة غير تنفيذية ولا تحتوي مجسمات أو محرك حركة.
