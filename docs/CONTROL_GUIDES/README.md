# Control guides

One guide per area. Each says what the owner sees, how a person does it in the Studio, and how an agent does it (scene data or
`node tools/mf.mjs`). Field details: [../SCENE_MANUAL.md](../SCENE_MANUAL.md). Ready-made edits: [../RECIPES.md](../RECIPES.md).

| area | guide |
|---|---|
| Camera (pad, mouse, guided camera, shots) | [CAMERA.md](CAMERA.md) |
| Trolleys (one or several, speed, congestion) | [TROLLEYS.md](TROLLEYS.md) |
| Paths and steps (routes, stops, elevator rides, straighten) | [PATHS_AND_STEPS.md](PATHS_AND_STEPS.md) |
| Objects and devices (PCs, RFID gates, scanners, 3D objects) | [OBJECTS_AND_DEVICES.md](OBJECTS_AND_DEVICES.md) |
| Layout (walls, doors, racks, machines, columns) | [LAYOUT.md](LAYOUT.md) |
| Director (camera keys, captions, video takes) | [DIRECTOR.md](DIRECTOR.md) |
| Numbers (distance, time, trips, compare) | [NUMBERS.md](NUMBERS.md) |
| Keyboard map (generated) | [KEYBOARD.md](KEYBOARD.md) |

There are no people or other "characters" in the engine yet: the moving things are trolleys (and the replica's own forklifts / AGVs,
which are decoration and not part of a scene).
