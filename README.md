# 🏭 المصنع الرقمي للتليفزيونات

خطة تأسيس محرك يمثل مصنع تليفزيونات متكاملًا في عرض ثنائي وثلاثي الأبعاد، مع تصميم حر للتخطيط، ومحاكاة الإنتاج والمناولة والعمال والمخازن والشحن.

**Status (2026-11-13): the engine core is built and tested (`engine/`, 9 tests pass): see [docs/17_ENGINE_CORE.md](docs/17_ENGINE_CORE.md). The data is still the declared sample; there is no measured factory model yet.**

Quick start: `node engine/cli.mjs validate examples/factory-blueprint.example.json`, then `npm run demo`, `npm test`.

تاريخ إعداد هذه الحزمة: ١٢ نوفمبر ٢٠٢٦.

## 🎯 ماذا نريد؟

- تمثيل حقن البلاستيك، وتشكيل الأجزاء المعدنية، وتجميع البوردات وبرمجتها، وتجميع موديولات الشاشات، وإنتاج الفوم، والتجميع النهائي والتعبئة.
- تمثيل الاستلام والفحص ومخازن الخامات والمنتج التام والشحن داخل الحاويات.
- تتبع العمال والتروليات والكلاركات والخامات والمخزون تحت التشغيل، مع تمييز الحركة المحسوبة عن الحركة المقاسة فعليًا.
- إضافة أي عنصر ونقله ونسخه وتعديل خصائصه، مع اكتشاف التداخل والمسارات غير الصالحة قبل اعتماد التغيير.
- مقارنة سيناريوهات تشغيل قابلة للتكرار، وفهم الإنتاجية والاختناقات والتكلفة.

## 🧱 القرارات الأساسية

١. حالة تشغيل واحدة موثوقة، يقرأها العرضان؛ الرسومات لا تنشئ مخزونًا أو تنهي عملية إنتاج.

٢. تنظيم إداري مستقل عن التركيب المكاني، وتكليف العامل مستقل عن مكانه، وحمولة التروللي مستقلة عن ملكيته الإدارية.

٣. المحاكاة تعمل بأحداث وزمن مستقل عن معدل إطارات الرسم؛ الحركة المستمرة لها تحديث يناسبها.

٤. تعريف المصنع، وحالة التشغيل، وسجل الأحداث مجموعات منفصلة بإصدارات معروفة.

٥. إعادة تخطيط المصنع تنتج نسخة قابلة للمراجعة والتراجع؛ لا تنقل شحنة أو عاملًا فجأة أثناء التشغيل.

٦. كل تحسين للأداء يحافظ على نتائج المحاكاة؛ التفاصيل البصرية تتغير مع التقريب دون تغيير الحقيقة الحسابية.

## 🚧 ما لم يُحسم بعد

محرك الرسم ولغة التنفيذ، ومواصفات الجهاز المستهدف، والأعداد الفعلية للعناصر، وبيانات المصنع، وأهداف الأداء النهائية. لا تمثل هذه الحزمة اختيارًا نهائيًا لتقنية أو ضمانًا لسرعة أو دقة لم تُقَس بعد.

الخطوة التالية المقترحة هي إثبات دورة صغيرة كاملة من الخامات إلى الشحن، ثم التوسع وفق [مراحل التنفيذ](docs/09_ROADMAP.md).
